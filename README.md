## 项目亮点

- 🏮 **实时程序化无限木构迷城**：基于 Three.js + WebGL 2，按「章节 → 街区（11 种建筑原型）→ 地块 → 房间 → 部件」分级程序化实时流式生成，无尽延伸且永不卡顿。
- 🐦‍⬛ **精雕 3D 鬼灭鎹鸦与六自由度飞行**：配备 Blender 精雕 3D 鎹鸦（分层羽翼、猩红颈巾、背负传信竹筒、绯红双瞳与翼流拖尾特效），支持 360° 翻滚、俯冲、滑翔、刹车悬停与第一/第三人称视角切换。
- ⚔️ **六大原作名场面 × 17 位真 3D 赛璐璐角色**：全部采用 Blender 4.5 精雕 GLB 真 3D 模型、1024px 平面正交面部贴图、4 阶赛璐璐着色与顶点法线外扩墨线描边，并附带真 3D 动态招式特效：
  1. **鸣女高台**：鸣女抚琵琶 + 恋柱·甘露寺蜜璃 & 蛇柱·伊黑小芭内 夹击突袭
  2. **无惨暗室**：鬼舞辻无惨立像 + 升腾猩红血雾丝缕
  3. **童磨莲池**：童磨（双金扇与浮空冰晶） vs 蝴蝶忍（3D 紫青幻蝶）+ 嘴平伊之助 + 栗花落香奈乎（飘零花瓣）
  4. **破晓罗针殿**：猗窝座（破坏杀·罗针冰环） vs 灶门炭治郎（日之呼吸火环）+ 水柱·富冈义勇（水之呼吸浪流）
  5. **雷渊悬桥**：我妻善逸（火雷神金雷） vs 狯岳（黑雷电弧）
  6. **残月古殿**：黑死牟（月之呼吸弧刃） vs 岩柱·悲鸣屿行冥 + 风柱·不死川实弥 + 霞柱·时透无一郎
- 🎵 **100% 原创和风 Web Audio 程序化音景**：基于 Web Audio API 实时合成 Karplus-Strong 琵琶拨弦、太鼓震响、风声呼啸与木构建造声景，无需任何外部版权音频文件。
- 🌫️ **动态天气与空间异变**：支持静谧、暖霭、雾瀑、烬暴、灰降、灵雾 6 种天气预设，按下 `B` 即可触发鸣女琵琶空间异变；内置「灵火狩猎」与「今日无限城」玩法模式。
- ⛩️ **全中文界面与神社设定面板**：完整中文化 HUD、引导教程与暂停神社菜单，支持画质档位自适应、场景一键传送、角色显隐开关与无 HUD 摄影模式。

## 操作指南

| 按键 / 操作 | 功能说明 |
| --- | --- |
| `Tab` / `Shift + Tab` | 一键巡礼切换 **六大原作名场面**（正向 / 反向） |
| `W` `A` `S` `D` | 名场面内自由前后左右漫游近距离观摩 3D 角色；翱翔模式下控制加速与转向（移出名场面边界自动恢复飞行） |
| 鼠标 / 方向键 | 六自由度自由转向与俯仰 |
| `空格` / `Shift` | 振翅冲刺 / 刹车悬停（漫游模式下控制升降） |
| `Q` / `E` | 左右横滚 |
| `P` | 手动切换 漫游探索 / 自由翱翔 模式 |
| `B` | 鸣女琵琶 · 手动触发空间异变 |
| `C` / `H` / `R` / `M` | 切换视角 / 摄影模式隐藏 HUD / 生成新世界种子 / 静音 |
| `Esc` | 打开 **神社设定菜单**（天气、光照、画质、名场面直达、声音与玩法设置） |

> 移动端自动启用虚拟摇杆、右侧滑动视角以及振翅 / 刹车触控按键。

## 本地开发与运行

需要 Node.js 20+ 与 pnpm（或 npm）：

```bash
# 安装依赖
pnpm install

# 启动本地开发服务器
pnpm run dev

# 类型检查与生产构建
pnpm run typecheck
pnpm run build
```

本地启动后可访问：
- 主场景：`http://localhost:5173/`
- 360° 独立 3D 角色/鎹鸦展台：`http://localhost:5173/preview-3d.html`

## 在线预览与自动部署

本项目已配置 GitHub Actions 自动构建并部署至 GitHub Pages（[.github/workflows/deploy.yml](.github/workflows/deploy.yml)）：

- **在线预览地址**：https://smallyyh0721.github.io/infinitecastle/
- 每次推送到 `main` 分支后，Actions 会自动执行类型检查、Vite 构建并发布到 GitHub Pages。
- 如首次启用，请确认仓库 **Settings → Pages → Build and deployment → Source** 已选择 **GitHub Actions**。

## 目录结构

```text
├── public/
│   └── models/          # 18 个 Blender 4.5 精雕真 3D GLB 模型（17 位角色 + 鬼灭鎹鸦）
├── src/
│   ├── audio/           # 原创 Web Audio 和风程序化音景（琵琶、太鼓、风声、木构）
│   ├── core/            # Three.js 渲染引擎、画质分级、种子哈希
│   ├── fx/              # 天空穹顶、雾层、浮尘、天气系统、后处理泛光
│   ├── input/           # 键鼠指针锁定与移动端触控摇杆
│   ├── kit/             # 程序化建筑部件库、和风材质与 4 阶赛璐璐 3D 着色器
│   ├── physics/         # 动态街区局部坐标系碰撞检测
│   ├── player/          # 3D 鬼灭鎹鸦、翼流特效与 6-DOF 飞行摄像机
│   ├── ui/              # 全中文入城界面、HUD、指引与神社设定菜单
│   └── world/           # 街区流式生成、六大名场面建筑与 17 位 3D 角色编排
└── .github/workflows/   # CI 与 GitHub Pages 自动部署工作流
```
